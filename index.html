1
Fase 01
Comprensión del Negocio
Define los objetivos del proyecto desde la perspectiva del negocio y traduce ese conocimiento en una definición del problema de minería de datos.
  • Determinar los objetivos del negocio
  • Evaluar la situación actual
  • Determinar los objetivos de minería de datos
  • Producir el plan del proyecto
2
Fase 02
Comprensión de los Datos
Recopila datos iniciales, los describe y explora para identificar problemas de calidad y obtener primeros insights.
  • Recopilar los datos iniciales
  • Describir los datos (EDA)
  • Explorar los datos
  • Verificar la calidad de los datos
3
Fase 03
Preparación de los Datos
Cubre todas las actividades para construir el dataset final. Esta fase consume el 80% del tiempo del proyecto.
  • Seleccionar los datos relevantes
  • Limpiar los datos (Data Munging)
  • Construir nuevas variables/features
  • Integrar y formatear los datos
4
Fase 04
Modelado
Selecciona y aplica diferentes técnicas de modelado, calibra sus parámetros y evalúa los resultados.
  • Seleccionar la técnica de modelado
  • Diseñar el plan de pruebas
  • Construir el/los modelos
  • Evaluar el modelo técnicamente
5
Fase 05
Evaluación
Evalúa el modelo desde la perspectiva del negocio y decide si se despliega o si hay que iterar.
  • Evaluar resultados vs objetivos del negocio
  • Revisar el proceso completo
  • Determinar los próximos pasos
  • ¿Desplegar o iterar? ← punto clave
6
Fase 06
Despliegue
Pone el modelo en producción para que el cliente o usuario final pueda utilizarlo y generar valor real.
  • Planificar el despliegue
  • Planificar el monitoreo y mantenimiento
  • Producir el informe final
  • Revisar el proyecto

↺ El proceso es iterativo — puedes volver a cualquier fase anterior

Proceso Iterativo
CRISP-DM no es lineal. Puedes (y debes) volver a fases anteriores cuando los hallazgos lo requieran. La iteración es su mayor fortaleza.
⚡
Agile + CRISP-DM
Combina CRISP-DM con Scrum o Kanban para entregar valor de forma incremental. El enfoque ágil acelera el feedback y reduce el riesgo.
📊
80% en Datos
La preparación de datos consume la mayor parte del esfuerzo. Invertir aquí define la calidad de todo lo demás en el proyecto.
📝
Documentación Justa
Documenta lo necesario para no frenar la entrega. Evita la burocracia: el objetivo es generar valor, no papeleo.
